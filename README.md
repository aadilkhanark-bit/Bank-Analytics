# Bank-Analytics

## Project Overview
This project focuses on analyzing two banking datasets: **Bank Credit & Debit Card Analysis** and **Bank Loan Analysis**. The main objective is to understand banking transactions, customer loan distribution, payment trends, loan performance, and branch-wise business performance.

Used Excel Power Query for data cleaning and transformation, SQL for data analysis, and Excel, Tableau, and Power BI to create multiple dashboards for different types of business analysis. **Power BI was used to develop the main interactive dashboards**, while Excel and Tableau were used for additional analysis and visualizations.

## Tools & Technologies
- **Excel Power Query:** Cleaned and transformed 100,000 credit and debit card records and 65,536 bank loan records.
- **SQL:** Used for data analysis, business requirements, and KPI calculations.
- **Excel:** Created additional dashboards for banking data analysis.
- **Tableau:** Developed interactive dashboards for different business insights.
- **Power BI:** Created the main interactive dashboards to analyze banking transactions and loan performance.

## Dashboards & Visualization
Created multiple dashboards in **Excel, Tableau, and Power BI** to perform different types of banking analysis. The main dashboards were developed in Power BI, focusing on credit and debit card transactions and bank loan performance. Additional dashboards in Excel and Tableau provided different views of the data and helped explore business insights.

## Project Objective
The objective of this project is to understand banking transaction patterns, analyze customer loan performance, identify defaults and delinquency, and compare branch-wise and regional performance through interactive dashboards. It helps convert raw banking data into meaningful business insights for better decision-making.
